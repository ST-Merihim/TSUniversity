# Практичні роботи з TypeScript (ПР1–ПР6)

Репозиторій містить набір практичних робіт з курсу TypeScript, виконаних у форматі окремих файлів та гілок Git.  
Кожна робота демонструє окремий аспект мови: базові типи, роботу з DOM, модулі, generics, enum-и та об’єктно-орієнтований підхід.

## Зміст

- **Практична робота №1**  
  Базове налаштування TypeScript-проєкту, файл `tsconfig.json`, приклад коду з використанням примітивних типів (`string`, `number`, `boolean`) та виведенням результату в консоль.

- **Практична робота №2**  
  Статична HTML-сторінка з інтерактивністю на TypeScript:
  модальне вікно, робота з подіями, акордеон, динамічне завантаження даних з API `jsonplaceholder.typicode.com` та відмальовування елементів на сторінці.

- **Практична робота №3**  
  Система управління розкладом в університеті на основі `type alias` і `union types`.  
  Робота з масивами, додавання занять, пошук конфліктів та простий аналіз розкладу.

- **Практична робота №4**  
  Рефакторинг коду з ПР2 у модульну структуру: винос логіки в окремі файли (`ui`, `data`, `types`), імпорт/експорт модулів та центральний файл `main.ts`.

- **Практична робота №5**  
  Реалізація базових компонентів інтернет-магазину з використанням generic-типів:  
  типобезпечні функції для пошуку товарів, фільтрації за ціною та роботи з кошиком.

- **Практична робота №6**  
  Система керування університетом з використанням `enum`, інтерфейсів та класу `UniversityManagementSystem`:  
  реєстрація студентів на курси, виставлення оцінок, оновлення статусу, розрахунок середнього балу та пошук «відмінників».
